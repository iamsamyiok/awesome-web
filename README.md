## 工程绘图

### [Mini-CAD 在线绘图（优化版）](https://bd2c9a77.pinme.dev)

轻量级在线 CAD。在初始版基础上增加了 DXF 导出（可与 AutoCAD 等主流 CAD 软件互通）、块管理（block / insert / explode）、极轴追踪、帮助面板与 Skill 使用文档。

- 绘图：直线 / 圆 / 矩形 / 多段线 / 多边形 / 圆弧 / 椭圆 / 样条 / 文字 / 填充 / 标注
- 编辑：复制 / 移动 / 旋转 / 镜像 / 阵列（矩形 + 环形）/ 缩放 / 偏移 / 修剪 / 延伸 / 圆角倒角 / 打断合并
- 系统：图层管理、对象捕捉（端点 / 中点 / 圆心 / 象限点 / 交点 / 网格点）、正交 / 极轴、命令行（按 `/` 聚焦）
- 输出：PNG / DXF 导出、打印
- 标注可配置：小数位、圆标注 R/Φ、五种箭头样式、标注比例、单位后缀

### [简易 CAD - SVG 编辑器（初始版）](https://f9ad69ee.pinme.dev/)

Mini-CAD 的前身版本，纯 SVG 绘图引擎。二十余种绘图与编辑工具一应俱全，带命令行、图层、捕捉、标注与测量，适合快速绘制平面图形。

## Markdown 工具

### [MD2Card](https://iamsamyiok.github.io/MD2Card/)

Markdown 转图片卡片工具（本地版）。无云端、无 API Key、全开源——排版数据不出浏览器，直接把 Markdown 渲染成可分享的精美卡片图。

### [MD Git Editor](https://d84738a1.pinme.dev)

带版本管理的在线 Markdown 编辑器。把 git 的分支与提交能力装进浏览器：

- 分支：新建分支、分支图可视化、分支对比、合并分支
- 版本：提交存档、一键回退、查看差异
- 导出：Markdown / HTML / 纯文本 / PDF
- 支持拖放导入、全屏模式、亮暗主题

### [极简 Markdown 工作站（AI 聊天版）](https://8ecc051a.pinme.dev)

Markdown 编辑器 + 内置 AI 助手侧栏（OpenAI 兼容 API 自行配置）：

- 资源管理器：本地文件、文件夹树、自动保存
- AI：发送选中 / 插入全文 / 插入到文档、荧光笔高亮
- 内置思维导图：8 种主题，导出 PNG / SVG / JSON / PDF
- 导出：MD / PDF / Word / TXT / PNG / HTML 六种格式

### [极简 Markdown 工作站（备份增强版）](https://c8ffd28b.pinme.dev/)

同上，新增数据存储与备份：数据可存本地文件夹（清浏览器数据不丢失），并支持按间隔自动备份到指定目录。

### [Private Markdown Editor](https://2559ee3c.pinit.eth.limo)

左右分栏实时预览的 Markdown 编辑器。四种主题（浅色 / 暗夜 / 复古羊皮纸 / 护眼绿）+ 自定义背景色，格式工具栏、字符统计、手动保存，界面复古精致。

## AI 与工作流

### [SMAW 高级多智能体工作流](https://f31fb197.pinit.eth.limo)

多智能体协同工作流引擎，可视化编排复杂 AI 任务：

- 编排：串行 / 并行执行、断点等待用户输入、拖拽调整节点顺序
- 智能体库：16+ 预设模板（需求分析师、全栈工程师、SWOT 等），支持 AI 自动生成智能体
- **Skill 系统**：能力扩展包（文本摘要、思维链、批评性思维等），关联后自动注入专业能力
- 多 LLM：OpenAI / 智谱 GLM / 任意兼容端点，每个节点可独立选模型
- 文件解析：PDF / Word / Excel / PPT / 图片自动解析为上下文；集成 OCR
- 变量系统：`{{变量名}}` 在节点间传递数据

### [LLM 迭代改进系统](https://cca441e3.pinme.dev/)

让 LLM 自我迭代直到达标：设定问题与评价标准（可 AI 生成 / AI 优化标准），自动多轮改进回答。

- 终止条件：达到迭代次数 / 达到目标分数（0-100）/ 先到者
- 对比视图：评分趋势、列表 / 并排 / 差异 / 按维度 / 改进率
- 评价标准库、历史记录、导出 MD 与对比报告

### [Mind Map Wizard（OpenRouter 版）](https://48bb64c3.pinit.eth.limo)

文本转思维导图，本地运行、使用自己的 OpenRouter API Key。支持联网搜索补充、上传文件、手动模式；导出 JPG / SVG / PDF / Markdown；节点可双击编辑、长按生成 AI 摘要，样式（分支位置 / 间距 / 圆角 / 字体）可深度自定义。

### [Mind Map Wizard（自定义 LLM 版）](https://be9b869c.pinit.eth.limo)

同上，改用自定义 OpenAI 兼容 API（Base URL + 模型名 + Key），Key 本地加密存储。

## 效率工具

### [RunPulse 跑步系统](https://5963bed3.pinme.dev/)

功能完备的跑步辅助 Web 应用：

- 记录：GPS 轨迹、配速、海拔、步频、步幅、卡路里
- 训练：训练计划库、目标管理、节拍器、语音播报
- 分析：配速趋势、周 / 月跑量、成就徽章、体重 BMI 跟踪
- 体验：天气显示、屏幕锁定、亮暗主题、数据导入导出备份

### [思维导图编辑器](https://de4a54ad.pinit.eth.limo)

简单易用的在线思维导图编辑器。16 种主题、自动整理布局、拖拽调整；右键菜单增删节点 / 改色 / 字号；截图可复制到剪贴板，另支持 PNG / JSON / Markdown 导出与导入。

### [鸿运当头 - 在线抽奖](https://9dae45c8.pinit.eth.limo/)

晚会 / 年会抽奖工具。名单输入或数字范围、一次抽取多人、滚动时长可调、有放回 / 无放回两种模式、自定义标题与中奖红榜，空格键开始。

### [在线录屏](https://1d0b1590.pinit.eth.limo/)

浏览器录屏为视频，自动加载 FFmpeg（wasm）完成编码，可选是否录入麦克风，无需安装任何软件。

## 通信与文件传输

> 去中心化思路：设备直连，文件与消息不经服务器中转。

### [P2P 局域网极速传（最优版）](https://e4e638bf.pinit.eth.limo)

同一 WiFi 下传输大文件，摆脱微信登录与限速。断开信令后完全隐身；启用本地 StreamSaver，大文件直写硬盘、内存零压力。

### [局域网工作室](https://4f2780ac.pinit.eth.limo)

局域网聊天 + 文件传输一体（WebRTC P2P）。成员列表、改名、表情、文件收发、新消息提醒——解决局域网中微信传大文件慢的痛点。

### [P2P 私密通信](https://cd774157.pinit.eth.limo)

可用于加密通信的 P2P 聊天室。房间制 + 隐身模式（隐身后从信令侧不可见），在线列表区分「仍连接信令」与「已隐身（安全）」状态。

### [P2P 平行世界](https://5eb22439.pinit.eth.limo)

在互联网中建立 P2P 链接传输文件（跨网络，非仅局域网）。明网（公开）/ 暗网（隔离）双模式，可全员隐身。
